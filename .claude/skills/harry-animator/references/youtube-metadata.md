# YouTube title, description and tags (one set per video)

Write these after the script is final and fact-checked. Everything in them must be true for the video; no claim that the
video doesn't make, no "you won't believe" bait. Save as `youtube.md` in the project and include it in the hand-off.

## Title (pick one, offer 2 alternates)
- 40-60 characters, the question or the surprising statement from the hook, sentence case.
- Curiosity from the real payoff ("What if all the water on Earth vanished?"), not from hype words
  (insane, shocking, mind-blowing) or ALL CAPS.
- No emoji spam; one at most, usually none.

## Description
1. Line 1 (shown in the feed, ~100 characters): a one-line restatement of the hook that adds one concrete detail.
2. 2-3 short sentences: what the video explains, in plain words, ending on the key fact (numbers as in the script).
3. A short honesty line when it applies: "Drawings are exaggerated for clarity; the Earth-and-water-ball comparison is to scale."
4. `Sources:` one line per source, name + URL (the same sources the script was checked against).
5. One soft subscribe line that matches the video's CTA ("Subscribe for the next what-if.").
6. 3 hashtags on the last line: `#Shorts` + 2 topical ones (e.g. `#Science #Earth`). YouTube shows the first 3 above the title.

## Tags
- 10-15 tags, comma-separated, under 500 characters total.
- Order: the exact topic phrase -> 2-3 phrasings people search ("what if water disappeared", "earth without water") ->
  the subject area (earth science, oceans) -> format (animated explainer, what if, shorts) -> 1-2 key facts (ocean depth).
- No other creators' or brands' names, no misleading or unrelated trending tags.

## Template
```
TITLE: <title>
ALT TITLES: <alt 1> | <alt 2>

DESCRIPTION:
<line 1>

<2-3 sentences>

<honesty line, if any>

Sources:
- <source name>: <url>
- ...

<subscribe line>

#Shorts #<Topic1> #<Topic2>

TAGS: <tag1>, <tag2>, ...
```
